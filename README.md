Вариант 8 «Определение реализационной цены продукции растениеводства»
Вводимые данные:
Вводимые данные:
Тип культуры: список: ячмень, озимая пшеница, подсолнечник
Производственная себестоимость 1 ц, тыс. руб.: поле ввода 
Объем реализации, ц: поле ввода
Аренда торговой точки, тыс. руб.: поле ввода 
Заработная плата продавцам, тыс. руб.: поле ввода
Кнопка Страховые взносы, тыс. руб. с выведением результата в отдельное поле
Маркетинговые расходы, тыс. руб.: поле ввода
Кнопка Уровень наценки, %: в зависимости от типа культуры
Кнопка Цена реализации с выводом в отдельное поле
Кнопка Сравнение цен с выведением в гистограмме данных о сумме фактически рассчитанной цене и плановой
Дополнительные данные:
Страховые взносы = з/п продавцам * процент страх. взносов
Процент страховых взносов = 30
Транспортные расходы = Объем реализации* Доставка 1 ц продукции, тыс. руб.
Культура	Уровень наценки, %
Ячмень	50
Озимая пшеница	35
Подсолнечник	45

Цена реализации = (Производственная себестоимость+ (Аренда торговой точки+З/п продавцам+Страховые взносы+ Маркетинговые расходы))*(1+процент наценки/100)
